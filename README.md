# Student Placement Prediction

A starter project combining exploratory data analysis and a baseline machine-learning classification workflow for student placement outcomes.

## Workflow
- Inspect and clean structured student data.
- Explore relationships between academic and skill-related features and placement.
- Prepare numeric and categorical features.
- Train a Logistic Regression baseline.
- Evaluate with accuracy, precision, recall, and F1-score.

## Tools
Python, pandas, NumPy, scikit-learn.

## Run
```bash
pip install -r requirements.txt
python train.py
```

## Dataset note
The script generates **synthetic demonstration data**. Replace it with the actual placement dataset before interpreting results or presenting model performance as real-world findings.
